# 한끼픽

현재 위치 주변의 실제 음식점을 한 장씩 넘겨보다가 마음에 드는 식당을 바로 선택하는 웹 프로토타입입니다.

## 가장 간단한 실행

[index.html](./index.html)을 더블클릭하면 됩니다.

1. 출발 위치를 정합니다. **현재 위치 불러오기**를 누르거나, 아래 입력칸에 주소·장소명을 넣고 **검색**해 고릅니다.
2. 예산, 남은 시간, 당기는 메뉴를 고르고 **내 주변 식당 찾기**를 누릅니다.
3. 별도 API 키나 `config.js` 설정은 필요하지 않습니다.

출발 위치를 직접 입력할 수 있으므로 접속하자마자 위치 권한을 묻지 않습니다.

인터넷 연결은 필요합니다. 브라우저 보안 설정으로 파일 직접 실행 시 위치 권한이 차단되는 특별한 경우에만 아래 방법을 사용하세요.

```powershell
python -m http.server 4173
```

그다음 `http://localhost:4173`을 엽니다.

## 사용 방법

- `←` 키 또는 왼쪽 스와이프: 다음 식당
- `→` 키 또는 오른쪽 스와이프: 현재 식당 즉시 선택
- 선택 화면: 카카오맵에서 식당의 정확한 좌표를 보거나 길찾기, OpenStreetMap 원본 장소 확인

## 장소 데이터

별도 키 없이 실제 장소를 찾기 위해 OpenStreetMap의 공개 데이터와 Overpass API를 사용합니다. 현재 좌표 주변의 `restaurant`, `fast_food`, `food_court` 장소를 검색합니다.

- 40분 조건: 반경 1,200m
- 60분 조건: 반경 2,000m
- 90분 조건: 반경 3,000m
- 도보 시간은 직선거리를 분당 70m로 환산한 참고값입니다.
- 위치 좌표는 저장하지 않고 현재 검색 요청에만 사용합니다.
- OpenStreetMap에 아직 등록되지 않은 국내 식당은 결과에 나오지 않을 수 있습니다.

## 출발 위치

- **현재 위치**: 브라우저 Geolocation API.
- **직접 입력**: OpenStreetMap Nominatim 지오코딩(`countrycodes=kr`)으로 주소·장소명을 검색해 후보 5개 중에서 고릅니다. 키가 필요 없는 대신 초당 1회 수준의 사용량 정책이 있어, 버튼을 눌렀을 때만 요청합니다.

두 방식 중 마지막으로 정한 위치가 검색 기준점이 됩니다.

## 가격 정보

**표시되는 가격은 실제 메뉴판 가격이 아니라 대표메뉴 시세 기준 추정치입니다.**

OpenStreetMap에는 식당별 메뉴 가격 태그가 없습니다. 그래서 상호명과 `cuisine` 태그에서 그 가게가 실제로 파는 대표메뉴를 먼저 찾고(예: `본가설렁탕` → 설렁탕, `역전우동` → 우동), 그 메뉴의 1인 시세를 붙입니다. 대표메뉴를 특정하지 못하면 업종 평균값으로 대체하고, 카드에는 `이 업종 평균 시세`라고 근거를 밝힙니다.

입력한 예산은 이제 표시용이 아니라 **추천 순서를 결정하는 1순위 기준**입니다. 정렬은 `예산 내 여부 → 선호 메뉴 일치 → 거리` 순이며, 예산을 넘는 식당은 제외하지 않고 뒤로 밀어 `예산 초과` 배지를 답니다.

실제 가격은 카드의 `메뉴·가격 확인` 링크로 카카오맵에서 확인합니다. 정확한 메뉴 가격이 필요하면 카카오 로컬이나 네이버 지역 검색 API(키 필요)를 붙이고 `estimateMenu()`가 돌려주는 값을 대체하면 됩니다.

## 식당 사진

키 없이 쓸 수 있는 범위에서 실제 사진을 붙입니다.

- OSM `image` 태그(https 주소)
- OSM `wikimedia_commons` 태그의 `File:` 항목
- `wikidata` / `brand:wikidata` 항목의 대표 이미지(P18) — 덱 전체를 한 번의 요청으로 조회

세 곳 모두 없으면 메뉴 종류별 이모지 카드로 표시합니다. 국내 개인 식당은 이 태그가 거의 없어 실제로 사진이 붙는 곳은 주로 체인점입니다. 모든 식당의 음식 사진이 필요하면 카카오·네이버 플레이스 API가 필요합니다. 사진에는 출처 배지를 함께 표시하고, 불러오지 못하면 조용히 이모지로 돌아갑니다.

## 분석용 익명 기록

가설이나 KPI는 서비스 화면에 표시하지 않습니다. 발표 준비에 필요한 넘김 횟수, 선택 횟수, 선택 시간, 만족도만 브라우저 `localStorage`에 저장합니다. 위치 좌표와 식당 이름은 저장하지 않습니다.

```js
HankkiPick.exportUsage() // 기록 확인
HankkiPick.clearUsage()  // 기록 초기화
```

장소 검색은 OpenStreetMap 데이터를 사용합니다. © OpenStreetMap contributors.
